# Vencord User Plugins by Xaenny

Custom [Vencord](https://github.com/Vendicated/Vencord) userplugins.

## Plugins

| Plugin | Description |
|---|---|
| **BetterFormattingRedux** | Formatting toolbar for chat (superscript, smallcaps, fullwidth, etc.) |
| **CustomLoadingLogo** | Replace Discord's loading screen logo with a custom image |
| **FavoriteMedia** | Save images, videos, and files as favourites in the GIF/Media picker |
| **SavedTexts** | Save and reuse text snippets from the expression picker |
| **HideGiftButton** | Hide the Nitro gift button in the chat bar |

## Installation

1. Clone or copy the plugin folders into your Vencord `src/userplugins/` directory.
2. Run `pnpm build` and `pnpm inject` from your Vencord install.
3. Enable the plugins in **Vencord Settings → Plugins**.
4. Restart Discord.
